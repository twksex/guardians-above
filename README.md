# 천 년 전의 경고 — 지붕 위의 수호자, 귀면와

국립중앙박물관 제안용 **비공식 시범 웹전시**. 공식 기관의 승인·제작·협력·후원을 의미하지 않습니다.

- 관람: https://twksex.github.io/guardians-above/?v=6
- 소스: https://github.com/twksex/guardians-above
- 청소년·성인 대상, 약 5~8분

## 이번 개선의 관람 흐름

**실제 유물 관찰 → 건축적 맥락 → 실물·창작 비교 → 개인 해석** 순서입니다. AI 캐릭터는 실제 사진을 관찰한 뒤 수동으로 공개합니다.

1. 프롤로그: 실제 정내894를 먼저 보고 질문·동선·시간을 확인합니다. 첫인상 선택은 선택 사항입니다.
2. 얼굴의 정체: 실제 정내902의 눈·입·테두리를 사진 밖 버튼으로 선택하면 해당 부위가 확대됩니다. 살펴본 단서를 기록하고 이후 창작 해석을 공개합니다.
3. 지붕 위의 수호자: 직접 만든 지붕 마루 개념도의 A/B를 선택해 일반적인 사용 맥락을 읽습니다. 세 유물의 원래 설치 위치를 복원한 자료가 아닙니다.
4. 서로 다른 얼굴들: **A 실제 유물 비교 / B 상상 속 수호자 비교**를 전환합니다. 선택한 작품은 유지되고 배율은 모드별로 관리합니다. 모바일에서는 왼쪽/오른쪽 카드 전환을 제공합니다.
5. 얼굴에 남겨진 마음: 처음 본 실제 유물을 다시 보고, 지키고 싶은 대상·상징·문장을 골라 개인 수호 상징 카드를 만듭니다. 텍스트를 복사할 수 있습니다.

AI 캐릭터의 몸·자세·이름·얼굴 겹침 위치, 개인 상징은 현대적 창작입니다. 학술적 복원이 아닙니다. 원본이라는 표현은 실제 소장품 사진에만 사용합니다.

## 유지·개선한 기능

- 다섯 화면, 해시 기반 이전·다음·브라우저 뒤로/앞으로 이동, 현재 단계와 진행률
- 공식 사진 3점, 유물별 같은 AI 캐릭터·얼굴 위 기와, 겹침 표시/숨김과 캐릭터 확대
- 실제 사진 확대·축소·초기화, 촬영 배경을 포함한 원본 보기, 유물 정보·공식 링크
- 관찰 부위 자동 확대, 관찰 진행 상태, 일반 건축 도식과 선택 해설
- 두 비교 모드, 작품 변경, 눈·입·윤곽·테두리 질문, 모드별 독립 배율, 비교 초기화
- 큰 글씨, 화면 효과 끄기, 시스템 모션 감소, 키보드 조작 이름·포커스 복원
- 개인 카드 생성·즉시 갱신·텍스트 복사, 복사 권한이 없으면 선택된 텍스트 제공
- 이미지 오류 안내, 숨긴 화면과 창작 이미지의 필요 시 생성, 우선 이미지 로딩

실제 크기 비례 비교와 결과 이미지 다운로드는 추가하지 않았습니다. 촬영 조건이 다른 사진에 검증되지 않은 비례를 적용하지 않고, 개인 결과는 안정적인 로컬 텍스트 복사로 제공합니다. 입력은 서버로 전송하거나 영구 저장하지 않습니다.

## 음악

기존 《곁을 지키는 밤》 MP3를 유지합니다. 가야금에서 영감 받은 80초 현악 **합성 음악**이며 실제 연주 녹음·고대 음악 복원이 아닙니다.

**기본 정지**입니다. 상단 전역 컨트롤의 재생을 눌러야 시작하며, 아무 곳을 클릭하거나 전시관을 이동해도 임의로 시작하지 않습니다. 정지는 음원 위치를 0으로 되돌립니다. 장면 이동은 사용자의 재생 상태를 바꾸지 않습니다. 탭을 벗어나면 일시정지하며 돌아와도 자동 재생하지 않습니다. 음량 슬라이더와 상태 안내, 확대 화면 안의 재생·정지를 제공합니다. 모바일 기기에 따라 시스템 음량 조절이 필요할 수 있습니다. 로딩·재생 실패가 관람을 막지 않습니다.

## 로컬 실행

ZIP을 풀어 `index.html`을 열거나, 프로젝트 폴더에서 다음을 실행합니다.

```sh
python -m http.server 8000
```

http://localhost:8000 에 접속합니다. Windows에서는 `py -m http.server 8000`을 사용할 수 있습니다. 종료는 Ctrl+C입니다. 실행에 설치·서버 API·로그인·외부 라이브러리는 필요하지 않습니다.

## 검증과 한계

Node.js v24.22.1, Python 3.12.14, jsdom 26.1.0에서 구문·파일 참조·이미지 디코딩/투명도·색상 대비·CSS 파싱·DOM 기능/회귀 검사를 수행했습니다. 실제 수정과 테스트 범위는 [review.md](review.md), [verification.md](verification.md)에 기록했습니다.

320/390/768/1024/1440px는 **모바일 상태 분기 검사**입니다. 실제 화면 배치, 200/400% 확대, 모바일 터치, 네이티브 모달의 포커스 가두기·Esc, 스크린리더, 실제 음향 출력·기기 음량은 미검증입니다. WCAG 인증이나 완전한 준수를 주장하지 않습니다. 지정 브라우저 검증 도구 부재로 수동 검증 목록을 남겼으며 시연 전 확인이 필요합니다. 교육용 PDF도 첨부되지 않아 검토하지 못했습니다.

선택적 개발 검사(관람에는 필요 없음):

```sh
node --check script.js
python tests/static.py
npm install --no-save --package-lock=false jsdom@26.1.0
node tests/dom.cjs
```

`node_modules/`는 게시하지 않습니다. Pillow가 없으면 이미지 디코딩만 미검증으로 표시됩니다. jsdom의 모달·미디어·클립보드 스텁 검사는 실제 브라우저 테스트와 다릅니다.

## GitHub Pages

저장소 **Settings → Pages → Deploy from a branch → main → /(root)**를 사용합니다. 파일 내용물을 최상위에 올리고 커밋하면 재배포됩니다. 상대 경로를 유지해 저장소 하위 주소에서도 실행됩니다. 공개 주소의 파일 제공 확인은 브라우저 조작 검증과 별도로 기록합니다.
