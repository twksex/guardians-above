# 천 년 전의 경고 — 지붕 위의 수호자, 귀면와

국립중앙박물관 제안용 **비공식 시범 웹전시**. 기관의 승인·협력·후원을 의미하지 않습니다.

- 관람: https://twksex.github.io/guardians-above/
- 소스: https://github.com/twksex/guardians-above
- 주요 대상: 청소년·성인, 관람 약 5~8분

## 이번 완성본의 관람 방식

각 귀면와에서 상상한 도깨비 캐릭터의 얼굴 위치에 **실제 소장품 사진**을 겹쳤습니다. 얼굴 위 기와를 누르면 해당 작품의 원본 확대·관찰 해설·크기·시대·출처가 열립니다. ‘기와 겹침 숨기기’로 상상한 얼굴만 볼 수도 있습니다.

캐릭터의 몸·복식·완성된 얼굴·겹침 위치는 **AI 창작 상상**이며 학술 복원도나 실제 건축 설치 위치가 아닙니다. 원본이라는 표현은 국립중앙박물관의 실제 사진에만 사용합니다.

하나의 자료 목록에서 유물·캐릭터·사진·겹침 위치를 관리하므로 같은 기와는 도입·관찰·비교·확대·마무리에서 같은 캐릭터로 표시됩니다.

| 유물 | 실제 사진 | 대응하는 AI 캐릭터 |
|---|---|---|
| 정내902 / 통일신라 | assets/A01.jpg | assets/guardian-A01.webp |
| 정내894 / 통일신라 | assets/A02.jpg | assets/guardian-A02.webp |
| 정내1031 / 고려 | assets/A03.jpg | assets/guardian-A03.webp |

## 구현 기능

- 다섯 단계 전시, 이전·다음·전시관 바로 이동, 진행률, 브라우저 뒤로/앞으로 가기
- 같은 작품의 일관된 캐릭터와 얼굴 위 실제 기와 합성, 기와 클릭 상세 확대
- 기와 겹침 표시/숨김, 캐릭터 확대·축소·초기화, 실제 기와 사진으로 이동
- 사진을 가리지 않는 **이미지 밖 눈·입·테두리 관찰 버튼**과 해당 부위 확대
- 세 작품 중 두 점 비교, 각 캐릭터 독립 확대·축소·겹침 조절, 비교 초기화
- 실제 사진 모달, 100~400% 확대·축소·초기화, 배경을 포함한 원본 보기
- 모달 닫기·Esc, 각 원래 조작 버튼으로 포커스 복원, 이미지 오류 안내
- 기본 18px 본문, 21px 큰 글씨 전환(브라우저 기본 글꼴 16px 기준), rem 단위
- 반응형 레이아웃, 키보드 포커스, 모션 감소와 효과 끄기, 이미지 비율 유지
- 감상 입력·선택, 처음부터 다시 보기. 감상은 서버에 전송하거나 영구 저장하지 않음

## 배경음악

《곁을 지키는 밤》은 가야금에서 영감 받은 **80초의 현악 합성 음악**입니다. 실제 가야금 연주 녹음이나 고대 음악 복원이 아닙니다. 외부 음원·샘플 없이 만들었습니다.

페이지를 열면 소리 있는 자동재생을 시도합니다. 브라우저가 차단하면 첫 클릭 또는 Enter/Space, 캐릭터 옆 **▶ 재생** 버튼으로 재생을 요청합니다. 브라우저 정책을 강제로 우회하지 않습니다.

상단 음악 바·음량 슬라이더·이퀄라이저·시간 표시는 제거했습니다. 캐릭터 옆 **재생·정지** 두 버튼이 한 음악을 함께 제어합니다. **정지**는 음악을 멈추고 처음으로 되돌리며 이후 다른 곳을 클릭해도 자동으로 다시 시작하지 않습니다. 다시 듣고 싶을 때 재생을 누르세요. 음량은 기기에서 조절합니다. 다른 탭으로 이동하면 일시정지합니다.

## 로컬 실행

프로젝트 ZIP을 풀고 `index.html`을 브라우저에서 열거나, 해당 폴더에서 실행합니다.

```sh
python -m http.server 8000
```

http://localhost:8000 에 접속합니다. Windows에서 `python` 대신 `py`를 사용할 수 있습니다. 종료는 Ctrl+C입니다. 실행 시 외부 라이브러리·CDN·API·데이터베이스가 필요하지 않습니다.

## 자료와 이미지 처리

국립중앙박물관의 실제 사진 3점을 원본 파일 그대로 보존했습니다. 각 공식 소장품 페이지에서 **공공누리 제1유형(출처표시)**을 확인했으며, 페이지에 기관명·작품명·번호·이용 조건·원문 링크를 표시했습니다. 자세한 검증은 [sources.md](sources.md)를 확인하세요.

화면에서는 CSS/SVG 외곽 마스크와 표시 영역으로 촬영 배경을 가립니다. 원본 픽셀을 AI로 다시 그리지 않았습니다. 실제 표면과 경계는 상세 화면의 ‘원본 사진 보기’에서 확인할 수 있습니다. 캐릭터 이미지는 별도 AI 창작으로 표시하고 유물의 사실 근거로 사용하지 않습니다. 캐릭터는 WebP로 최적화해 PNG 시안 대비 전송 용량을 약 87% 줄였습니다.

## 검증

- JavaScript 구문, HTML ID 중복, 파일 참조, 사진 대체 텍스트, 기본 텍스트 색상 대비 검사 통과
- DOM 통합 검사: 유물별 같은 캐릭터와 같은 겹침 위치, 모든 비교 선택, 번호 없는 관찰, 모달·확대·원본 전환·포커스 복원, 재관람 통과
- 미디어 API 스텁 검사: 자동재생 허용/거절, 첫 조작 후 재생, 공통 재생·정지, 처음으로 되돌리기, 정지 뒤 자동 재시작 방지, 재생 대기 취소, 탭 이동 시 정지 통과
- 음악 MP3 전체 디코딩과 클리핑 없음 확인. 주요 글자 색의 배경 대비 6개 조합은 4.5:1 이상
- **실제 브라우저 렌더링·얼굴 겹침 경계·모바일 터치·스크린리더·네이티브 모달·실제 자동재생 정책·청취는 미검증**. DOM 검사를 실제 브라우저 검사로 간주하지 않음

[관람자 관점 검토와 수정 기록](review.md), [검증 기록](verification.md)에 완료 범위와 미검증 항목을 구분했습니다. WCAG 인증 또는 모든 환경에서의 완전 준수를 주장하지 않습니다. 교육용 PDF는 첨부되지 않아 검토하지 못했습니다.

선택적 개발 검사(감상에는 필요하지 않음):

```sh
node --check script.js
python tests/static.py
npm install --no-save --package-lock=false jsdom@26.1.0
node tests/dom.cjs
```

`node_modules/`는 저장소에 올리지 않습니다. Pillow가 없으면 `static.py`의 이미지 디코딩만 미검증으로 표시됩니다.
