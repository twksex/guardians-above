# 천 년 전의 경고
## 지붕 위의 수호자, 귀면와

국립중앙박물관 제안용 **비공식 시범 웹전시**. 공식 기관의 사업·승인·협력·후원을 의미하지 않습니다. 청소년·성인 관람객을 위한 5~8분의 인터랙티브 전시입니다.

HTML5·CSS3·Vanilla JavaScript만 사용합니다. 실행 시 외부 패키지, CDN, API, 서버, 데이터베이스가 필요하지 않습니다. 사진 3점을 로컬에 포함했습니다. 상대 경로를 사용하므로 GitHub Pages의 저장소 하위 경로에서도 동작하도록 구성했습니다.

## 로컬 실행

1. ZIP을 내려받아 압축을 풉니다.
2. 간단히 보려면 `index.html`을 최신 Chrome, Edge, Firefox, Safari에서 엽니다.
3. 서버 방식으로 테스트하려면 프로젝트 폴더에서 아래 명령을 실행합니다.

```sh
python -m http.server 8000
```

Windows에서 `python`이 없다면 `py -m http.server 8000`을 사용합니다. 이후 브라우저에서 http://localhost:8000 에 접속합니다. 종료는 터미널에서 Ctrl+C입니다. Python이 없으면 VS Code의 Live Server로 `index.html`을 열어도 됩니다.

## GitHub Pages로 감상하기

GitHub의 저장소 파일 화면은 HTML 웹전시를 실행하지 않습니다. **GitHub Pages**를 켜야 웹사이트로 감상할 수 있습니다.

1. GitHub에 새 저장소를 만듭니다. 무료 Pages를 이용하려면 공개 저장소로 만듭니다.
2. 이 폴더의 **내용물**을 저장소 최상위에 올립니다. `index.html`과 `assets/`가 최상위에서 보여야 합니다. ZIP 파일 자체나 바깥 폴더 한 개만 올리지 않습니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 선택하고 Save를 누릅니다. 브랜치명이 다르면 실제 기본 브랜치를 선택합니다.
5. 배포가 끝나면 Pages 설정에 표시된 실제 방문 링크로 접속합니다.
6. 수정한 파일을 같은 브랜치에 커밋하면 다시 배포됩니다. 사진을 재배포할 때 기관명·작품명·공공누리·원문 출처를 유지하세요.

소스 업로드 완료: https://github.com/twksex/guardians-above

GitHub 앱 인증으로 Pages 활성화를 시도했지만 HTTP 403(Resource not accessible by integration)으로 거부되었습니다. 저장소 소유자가 아래 설정에서 `Deploy from a branch → main → /(root) → Save`로 활성화해야 합니다.

Pages 설정: https://github.com/twksex/guardians-above/settings/pages

공개 배포 성공 및 실제 관람 URL은 아직 확인하지 못했습니다.

## 프로젝트 구조

```text
guardians-above/
├── index.html          다섯 전시관과 접근 가능한 기본 구조
├── style.css           검정·금색 디자인, 반응형, 모션 감소 대응
├── script.js           전시 이동, 관찰, 비교, 사진 뷰어, 출처, 재관람
├── assets/
│   ├── A01.jpg         정내902 (3000 × 2000)
│   ├── A02.jpg         정내894 (618 × 600)
│   └── A03.jpg         정내1031 (668 × 515)
├── plan.md             기획, 자료 선정, 관람 행동, 완료 기준
├── sources.md          공식 정보, 원본 URL, 이용 조건, 미확인 정보
├── prompts.md          제작 요청과 적용 방침
├── README.md           실행, 공개, 검증 및 제한
├── tests/
│   ├── static.py       파일 참조, ID, 대체 텍스트, 색상 대비 검사
│   └── dom.cjs         선택적 jsdom 기능 통합 검사
├── research/           확인 당시 공식 페이지 및 권리 조건 HTML
├── verification.md     실제 검사 결과와 수동 확인 목록
└── .nojekyll           GitHub Pages 정적 파일 게시
```

## 구현한 기능

- 도입 → 얼굴 관찰 → 역사적 맥락 → 두 작품 비교 → 재해석의 다섯 화면
- 시작·이전·다음·전시관 바로 이동, 진행률, URL 해시 및 브라우저 뒤로/앞으로 이동
- 정내902의 눈·입·테두리 관찰 지점 선택과 해당 부위 확대
- 세 작품 중 두 점을 선택, 독립적인 100~300% 확대·축소, 비교 초기화
- 원본 사진 뷰어의 100~400% 확대·축소·초기화, 넘친 사진의 스크롤 탐색
- 네이티브 `dialog` 모달, 닫기, Esc, 모달 종료 후 기존 버튼 포커스 복원
- 공식 소장품 출처·이용 조건 보기, 이미지 오류 시 안내
- 반응형 레이아웃, 키보드 포커스 표시, 본문 건너뛰기, 모션 감소 설정 지원, 화면 효과 끄기 버튼
- 감상 선택과 240자 생각 기록, 처음부터 다시 보기

감상은 메모리에만 존재하며 새로고침·재시작 시 사라집니다. 서버로 전송하지 않습니다. 프로그램은 실제 3D 파일을 사용하지 않으며 3D 회전을 제공하지 않습니다.

## 확보한 자료와 권리

국립중앙박물관 공식 자료의 **도깨비얼굴무늬 기와** 3점:

| 파일 | 소장품번호 | 시대 | 사진·정보 상태 |
|---|---|---|---|
| A01.jpg | 정내902 | 통일신라 | 공식 정보·원본 사진·공공누리 제1유형 확인 |
| A02.jpg | 정내894 | 통일신라 | 공식 정보·원본 사진·공공누리 제1유형 확인 |
| A03.jpg | 정내1031 | 고려 | 공식 정보·원본 사진·공공누리 제1유형 확인 |

기관 사진의 출처는 국립중앙박물관이며 **공공누리 제1유형(출처표시)** 조건을 따릅니다. 이미지 파일을 편집하지 않았습니다. A02·A03은 원본 해상도가 낮아 고배율에서 선명도가 제한됩니다. 역사적 맥락은 한국문화정보원의 문화포털 해설을 참조했습니다. 자세한 공식 링크와 각 작품의 크기·재질은 [sources.md](sources.md)에 기록했습니다.

## 실제 검증 결과

- `node --check script.js`: 통과.
- `python tests/static.py`: 참조 파일 존재, HTML ID 중복 없음, 사진 대체 텍스트, 사진 파일 디코딩 통과.
- 주요 텍스트 3색을 배경 2색과 조합한 6개 대비: 모두 WCAG AA 일반 텍스트 기준 4.5:1 이상. 수치는 verification.md에 기록.
- jsdom 통합 검사: 화면 이동, 제목 포커스, 진행률, 관찰 지점, 확대·초기화, 모달 종료 후 포커스 복원, 비교 유물 변경·확대·초기화, 출처 목록, 이미지 오류, 감상 기록, 재시작, 뒤로가기 연결 통과.
- **실제 브라우저 렌더링·모바일 터치·키보드 전체 관람·스크린리더·네이티브 모달의 포커스 가두기와 Esc·file:// 실행·GitHub Pages 배포는 미검증**입니다. DOM 검사를 실제 브라우저 테스트로 간주하지 않습니다. WCAG 2.2 AA 인증 또는 완전한 준수를 주장하지 않습니다.

선택적 개발 검사를 다시 실행하려면 Python과 Node.js가 필요합니다. 웹전시 감상에는 필요하지 않습니다.

```sh
node --check script.js
python tests/static.py
# DOM 검사만 추가 실행하려면 테스트 의존성을 별도 설치합니다.
npm install --no-save --package-lock=false jsdom@26.1.0
node tests/dom.cjs
```

검사 설치로 만들어진 `node_modules/`는 GitHub에 올리지 않습니다. Pillow가 없는 환경에서 `static.py`의 사진 디코딩 검사는 미검증으로 표시됩니다.

## 수정한 문제와 남은 작업

초기 점검에서 사진 뷰어의 기본 대체 텍스트가 비어 있던 부분을 보완했습니다. 모달 닫기 뒤 포커스 복원, 재시작 시 선택·배율·감상 초기화, 이미지 로드 실패 안내를 DOM 검사로 확인했습니다.

교육자료 PDF는 첨부되지 않아 반영 여부를 확인하지 못했습니다. 추가 후보 정내899·정내887은 사용하지 않았습니다. 개별 유물의 정확한 원래 건물·설치 위치·제작 의도는 미확인으로 남겨 추정 복원을 하지 않았습니다. 실제 박물관 제출 전에는 학술 검토와 [수동 검증 목록](verification.md)을 수행해야 합니다.
